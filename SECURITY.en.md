# Security Policy

[简体中文](SECURITY.md) · **English**

## Supported version

Security fixes target the latest version of the default branch.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** flow to submit a private report. Do not open a public issue first.

Please include:

- the affected route or file;
- reproduction steps;
- potential impact;
- a suggested fix, if available.

Do not access other users' accounts, bypass authorization, or disrupt services while testing.
